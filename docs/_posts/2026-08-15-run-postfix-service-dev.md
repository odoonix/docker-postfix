## ساختار پروژه

تمام کارهایی که برای اجرا انجام دادیم توی پوشه‌های زیر هست


### .github

### .vscode



### api

این پوشه یه سرویس به زبان پایتون هست که دسترسی به سرویس ایمیل را فراهم می‌کند.

این واسطه به صورت یک REST API عمل می‌کنه و می‌تونه ایمیل‌ها رو دریافت و ارسال کنه.


### bin

یه سری اسکریپت هست که برای راه‌اندازی و مدیریت سرویس‌ها استفاده می‌شه. این اسکریپت‌ها شامل موارد زیر هستن:

- api.sh
- opendkim.sh
- postfix.sh
- run.sh


### config

این پوشه یه سری تنظیم‌های اولیه است که زمان اجرا توی داکر لود می‌شود. البته زمانی که شما پروژه رو در محیط
واقعی اجرا می‌کنید می‌تونید این فایلها رو توی یه پوشه سیستم میزبان ایجاد کنید و انها رو مدیریت کندی.

### docker

توی این پوشه یک docker-compose.yml هست که شامل سرویس‌های زیر هست:

- postfix
- postgres

اولی یک سرویس ایمیل کامل شامل Postfix و Dovecot هست که می‌تونه ایمیل‌ها رو دریافت و ارسال کنه و دومی هم یک سرویس دیتابیس PostgreSQL هست که برای ذخیره‌سازی داده‌ها استفاده می‌شه.

دومی هم یک پایگاه داده است که برای ذخیره‌سازی داده‌ها استفاده می‌شه.


### doc

تمام کدهایی که برای راه اندازی وب سایت طراحی شده توی این مسیر قرار داره.

ساختار مستند سازی بر اساس مدل Jekyll هست و می‌تونه به صورت خودکار مستندات رو تولید کنه.

این مستند به صورت خودکار به یک وبسایت تبدیل شده و به صورت آنلان در اختیار برنامه 
نویس‌ها قرار می‌گیرد.

### test

یه سری فایل برای تست کردن کل سیستم توی این مسیر قرار گرفته است.
